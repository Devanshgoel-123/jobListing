# jobListing

### Job board UI in vanilla JavaScript

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

A job board page with category cards (web development, app development, cyber security, tutoring, stock trading). It also has a "new job" form whose country and state dropdowns are filled from the CountryStateCity API with `fetch`.

Open `index.html` in a browser; no build step needed.
